# Trilha de Estudos em Tecnologia

Repositório dedicado ao registro da minha evolução em tecnologia e desenvolvimento de software.

## Objetivo
Organizar materiais e atividades de aprendizado, mantendo um histórico consultável dos estudos.

## Áreas de interesse
- Desenvolvimento back-end com Java
- Bancos de dados relacionais e SQL
- Linux, Git e ferramentas de desenvolvimento
- Cloud, DevOps e segurança da informação

## Observação
Este repositório reúne materiais de estudo. Projetos práticos independentes são mantidos em repositórios próprios.
